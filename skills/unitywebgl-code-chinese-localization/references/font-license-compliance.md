# 十六、字体版权合规与非商业字体资源管理

## 16.1 核心原则

所有 AI 汉化过程中新增、替换或生成的中文字体，必须优先使用许可证明确、来源可靠、允许当前使用方式的字体。

核心目标：

- 避免侵犯字体著作权。
- 避免未经授权使用商业字体。
- 避免使用来源不明的字体文件。
- 优先采用开源或明确允许非商业使用的中文字体。
- 提前建立本地合法字体资源库。
- 确保字体允许嵌入、修改和随游戏资源分发。

不得因为字体能够免费下载，就认定其可以自由使用。

## 16.2 字体使用优先级

按照以下顺序选择：

第一优先级：原游戏自带且允许继续使用的中文字体。

第二优先级：采用 SIL Open Font License（OFL）等明确开源许可的字体。

第三优先级：明确允许非商业使用、嵌入和修改的字体。

第四优先级：其他具有明确授权文件的字体。

禁止使用：

- 来源不明的字体。
- 未授权商业字体。
- 从其他游戏中提取的字体。
- 仅提供个人预览许可的字体。
- 未确认是否允许重新分发的字体。
- 许可证禁止修改或嵌入的字体。

## 16.3 推荐预备字体库

优先准备以下开源中文字体：

### 思源黑体（Source Han Sans）

- 字体类型：无衬线黑体。
- 适用场景：游戏 UI、菜单、按钮、系统提示。
- 风格：现代、清晰、通用。
- 许可：SIL Open Font License 1.1。

### 思源宋体（Source Han Serif）

- 字体类型：宋体。
- 适用场景：剧情、小说、古风游戏、标题。
- 风格：典雅、传统、阅读感强。
- 许可：SIL Open Font License 1.1。

### Noto Sans SC

- 字体类型：简体中文无衬线字体。
- 适用场景：现代游戏 UI、任务文本、对话。
- 风格：简洁、易读。
- 许可：SIL Open Font License 1.1。

### Noto Serif SC

- 字体类型：简体中文衬线字体。
- 适用场景：剧情文本、古风界面、书籍风格界面。
- 风格：优雅、正式。
- 许可：SIL Open Font License 1.1。

### LXGW WenKai（霞鹜文楷）

- 字体类型：楷体风格。
- 适用场景：古风游戏、剧情对话、文艺风格 UI。
- 风格：自然、柔和、具有书写感。
- 许可：SIL Open Font License 1.1。

注意：实际使用前必须核实具体字体版本附带的 LICENSE 文件及其适用范围。

## 16.4 字体预备目录

提前建立本地字体库：

FontLibrary/
├── Sans/
│   ├── SourceHanSansSC/
│   └── NotoSansSC/
├── Serif/
│   ├── SourceHanSerifSC/
│   └── NotoSerifSC/
├── Artistic/
│   └── LXGWWenKai/
├── License/
│   ├── OFL/
│   └── LICENSE_RECORDS/
└── FontManifest.json

每种字体必须同时保存：

- 字体文件。
- LICENSE 文件。
- 原始下载来源。
- 版本号。
- 字体名称。
- 许可类型。
- 是否允许修改。
- 是否允许嵌入游戏。
- 是否允许随游戏重新分发。
- 是否需要附带版权声明。

## 16.5 自动字体选择策略

根据游戏视觉风格自动匹配字体：

| 游戏风格 | 优先字体 |
|---|---|
| 现代都市 | 思源黑体 |
| 科幻游戏 | 思源黑体 |
| 二次元游戏 | Noto Sans SC |
| 东方仙侠 | 思源宋体 |
| 古风 RPG | 霞鹜文楷 |
| 西方奇幻 | 思源宋体或思源黑体 |
| 休闲游戏 | Noto Sans SC |

必须优先考虑原游戏字体的视觉特征，避免字体替换后破坏整体美术风格。

## 16.6 字体版权检查

每次使用新字体之前，必须执行：

1. 确认字体真实来源。
2. 确认字体版本。
3. 检查 LICENSE 文件。
4. 确认允许非商业使用。
5. 确认允许游戏内嵌。
6. 确认允许修改或生成字形子集。
7. 确认允许重新分发。
8. 按许可证要求保留版权声明。
9. 将字体登记到 FontManifest.json。

如果许可条件不明确，禁止自动使用，进入人工审核队列。

## 16.7 字体技术适配

不能只替换字体文件。

必须检查：

- TTF / OTF 格式。
- WebGL 字体加载兼容性。
- TextMeshPro 字体资源。
- 字体图集。
- Fallback Font。
- 中文字符覆盖范围。
- 字体材质。
- 字体资源引用。
- 字体文件体积。

如果游戏使用 TMP 静态字体图集，需要确保所需汉字已经生成并且能够正常加载。

如果游戏支持动态字体或字体回退，可以优先利用现有机制。

## 16.8 字体版权交付

最终报告必须包含：

- 使用的字体名称。
- 字体版本。
- 字体来源。
- 许可证类型。
- LICENSE 文件。
- 字体修改记录。
- 字体是否嵌入游戏。
- 是否随最终游戏文件分发。

如果无法确认授权，必须标记为：

FONT_LICENSE_UNVERIFIED

不得宣称字体已经通过版权审核。

## 16.9 最终强制规则

所有视觉汉化字体必须满足：

**来源可追溯、许可证可核实、使用方式被授权、版权声明完整。**

优先使用开源中文字体，提前建立字体资源库，避免在汉化过程中临时寻找来源不明的商业字体。

不得为了追求视觉效果而牺牲字体版权合规性。
