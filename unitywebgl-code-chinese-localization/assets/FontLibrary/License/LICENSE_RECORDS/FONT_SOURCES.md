1. 随游戏分发时必须附带对应 OFL 许可证与版权声明。
2. OFL 含保留字体名（Reserved Font Name）的字体（思源黑体/宋体保留名 "Source"），修改后的版本不得继续使用保留名。
3. 生成字形子集属于修改，需遵守 OFL 第 3 条，并在交付报告中登记。
4. 本记录不代表已完成游戏项目的最终版权审核；游戏实际使用字体时按字体文档 16.8 节输出交付信息。
